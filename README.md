# 🌟 Programa de Boas-Vindas em JavaScript

🚀 **Projeto introdutório para iniciantes em programação**  
🧩 Interação direta com o usuário no navegador

---

## 🖥️ Linguagens & Tecnologias Utilizadas

- 🟧 **HTML5** — Estrutura da página  
- 🟨 **JavaScript** — Lógica e interação com o usuário  

---

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de **introduzir os conceitos básicos de JavaScript**, focando na **interação com o usuário** por meio do navegador.

Ao abrir a página, o usuário informa seu nome em uma caixa de diálogo. Em seguida, o sistema exibe uma **mensagem de boas-vindas personalizada**, criando uma experiência simples e interativa.

📌 É um projeto ideal para quem está dando os **primeiros passos na programação web**.

---

## 🎬 Demonstração do Funcionamento

🧑‍💻 O usuário acessa a página  
⌨️ Digita seu nome quando solicitado  
👋 Recebe uma mensagem de boas-vindas personalizada  

### **🧠 Conceitos Abordados**
Durante o desenvolvimento deste projeto, são trabalhados os seguintes conceitos:

- ✔️ Declaração de variáveis  
- ✔️ Entrada de dados com `window.prompt()`  
- ✔️ Saída de dados com `document.write()`  
- ✔️ Concatenação de strings  
- ✔️ Integração entre HTML e JavaScript  
- ✔️ Comunicação entre usuário e navegador
